How to read one

Selection by salience. Every candidate claim is scored and only the ones that moved get into the summary. When nothing moved, it says so, which over time is more informative than manufactured drama.

Banded vocabulary. A delta maps to a fixed phrase — “was broadly flat”, “rose sharply”, “more than doubled” — rather than interpolating a percentage into a sentence. Percentages go in the table.

Set differences, never subtracted lifetimes. A dossier's credential count covers the whole retention window, so week-over-week movement comes from what is newly present or newly absent — never from subtracting two lifetime sums, which would produce a number that is not about the period it appears to describe.

Lyrebird

What reaches an ordinary internet address: a continuous record from one honeypot, published as data. Services are emulated; no real host was compromised. Attacker input is reproduced verbatim and is hostile by definition — do not execute anything recorded here.
