What a page contains

Source, country, first and last seen, sessions and events; the vulnerabilities targeted and the technique classes; the credentials attempted; the commands typed, verbatim; the paths requested; the user agents sent; the payload URLs fetched, defanged; the samples delivered, with their archives; and the detections that fired.

Every field is something the attacker supplied. Lyrebird's responses are not read by the generator, so they cannot appear — the guarantee is in what the function touches, not in a filter applied afterwards. Attacker private keys are reduced to fingerprints: the body is not ours to republish.

A page describes technique and sequence. It deliberately stops short of attribution — see how to read this data.

Lyrebird
